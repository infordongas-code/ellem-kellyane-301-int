# Prato Feliz — Cardápio Escolar

Projeto de exemplo com HTML, CSS e JavaScript. O site apresenta sugestões de refeições para os cinco dias úteis e permite trocar o dia por meio dos botões.

## Arquivos
- `index.html` — estrutura e conteúdo
- `style.css` — cores, layout e responsividade
- `script.js` — troca interativa do cardápio e menu móvel

## Como abrir no Visual Studio Code
1. Extraia o ZIP.
2. Abra esta pasta no VS Code.
3. Abra `index.html` no navegador, ou use a extensão Live Server.

## Observação
Este é um cardápio ilustrativo para fins escolares. O cardápio oficial deve ser confirmado com a escola e adaptado às orientações nutricionais, alergias e necessidades dos alunos.
